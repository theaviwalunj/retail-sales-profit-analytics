# Retail Sales & Profit Analytics

## 📌 Project Overview

This project analyzes retail sales and profitability using the Superstore dataset.

The goal is to identify sales trends, profitable categories and regions, top-performing products, and loss-making products using Python, SQL, and Tableau.

---

## 🎯 Business Objectives

- Analyze overall sales and profit performance
- Identify top-performing categories and regions
- Analyze monthly sales trends
- Identify top-selling products
- Identify loss-making products
- Calculate overall profit margin
- Build an interactive Tableau dashboard
- Generate business insights to support decision-making

---

## 🛠️ Tools & Technologies

- **Python** — Data cleaning and analysis
- **Pandas** — Data manipulation
- **Matplotlib** — Data visualization
- **SQL / SQLite** — Business analysis
- **Tableau** — Interactive dashboard
- **VS Code** — Development environment
- **GitHub** — Project documentation and portfolio
